# 🎬 Кинотеатр Онлайн (Вариант 4)🎥
Проект представляет собой веб-приложение, предназначенное для управления информацией о фильмах, киносеансах, залах и билетах онлайн-кинотеатра. Проект разработан на платформе FastAPI с использованием СУБД SQLite и библиотек SQLAlchemy для работы с базой данных.

## ⚙️ Технологии и Версии
Backend: FastAPI v0.0.7
ORM: SQLAlchemy v2.0.40
Database: SQLite
Validation: Pydactic v2.8.1
Authentication: Basic Auth
Documentation: OpenAPI/Swagger

## 📌 Функционал Приложения
Приложение включает следующий основной функционал:

- Просмотр списка фильмов с возможностью фильтрации по жанрам и оценкам.
- Создание новых фильмов, редактирование существующих и удаление ненужных.
- Управление расписаниями кинозалов и создание киносеансов.
- Продажа билетов на конкретные сеансы и контроль доступности мест.
- Авторизация пользователей с ролями администратора, кассир и зритель для контроля доступа.

## 💨 Установка и Запуск приложения
1. Активация .venv
```codeline

```


## ✅ Валидаторы ключевых эндпоинтов
Все POST и PUT методы используют классы Pydactic для валидации входных данных. Например, создание нового фильма требует обязательного ввода полей, включая название, премьера, продолжительность и жанр.
Для авторизации используется basic auth с проверкой пароля и роли пользователя.

### Валидация ключевого эндпойнта
```
GET /api/movies?page=1&limit=10&genre=comedy&minRating=7
```
Query Parameters:
- page: номер страницы, целое число, минимальное значение равно 1.
- limit: количество фильмов на одной странице, максимальное значение ограничено 10.
- genre: строковое значение, которое является необязательным (может отсутствовать).
- min_rating: минимальный рейтинг фильма, также необязателен.

## 👩‍💻 Роли Пользователей и Права Доступа
Администратор (role_id=1): Полный доступ ко всему функционалу системы, включая возможность удаления данных.
Кассир (role_id=3): Доступ ко всей функциональности кроме удаления фильмов, удаление пользователей и изменения ролей пользователей.
Зритель (role_id=2): Могут просматривать информацию о фильмах, залах, жарнах, имеют возможность регистрироваться и редактировать свои данные.
